Arquitetura TCP/IP e Conceito de Pilha

Clique nas camadas coloridas para descobrir a função de cada uma antes do jogo!

1. Aplicação HTTP, WhatsApp, DNS
📌 Função no Jogo: É onde tudo começa! Cria a mensagem original e faz a primeira operação PUSH (Empilhar) no envio dos dados.
2. Transporte TCP e UDP
📌 Função no Jogo: Divide as mensagens longas e adiciona as Portas de Comunicação para identificar o programa correto.
3. Internet IP (Endereçamento)
📌 Função no Jogo: Responsável pelo roteamento! Adiciona o Endereço IP de origem e destino no pacote de dados.
4. Acesso à Rede Ethernet, Frame Relay
📌 Função no Jogo: A última camada no envio e a primeira no recebimento! Transforma os pacotes em sinais físicos (cabo de rede ou Wi-Fi).

O Conceito de Pilha (LIFO) e a Analogia dos Pratos

🍽️ Exemplo dos Pratos: O último prato colocado no topo é obrigatoriamente o primeiro a ser retirado. Regra LIFO (Last In, First Out).
🌐 Analogia com o TCP/IP: • PUSH (Empilhar): No envio, adicione o envelope no topo.
• POP (Desempilhar): No receptor, retire primeiro o envelope mais externo!
